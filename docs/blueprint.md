# **App Name**: Gridiron Guesser

## Core Features:

- Real-time Prediction: Display the current play and allow users to predict the next move (Run or Pass, etc.) within a limited time frame.
- Live Data Integration: Fetch real-time play-by-play data from Genius Sports or SportsDataIO to drive the game.
- Score Tracking: Calculate scores based on prediction accuracy, with bonus points for streaks and correct deep cut predictions.
- Leaderboard: Display a real-time leaderboard to show user rankings and scores.
- Game State Management: Manage game state and leaderboard updates using Redis.
- Sync Offset: Implement a manual "Sync Offset" setting allowing users to adjust the timing of question appearance.

## Style Guidelines:

- Primary color: Electric Blue (#7DF9FF) for a vibrant, energetic feel, referencing the fast-paced nature of football and digital aesthetics.
- Background color: Dark Gray (#222222) to create a "Sports Bar" chic dark mode environment.
- Accent color: Action Green (#2ECC71) used to highlight key interactive elements and important information.
- Body and headline font: 'Space Grotesk', a sans-serif with a techy feel, suitable for headlines and shorter body texts.
- Use simple, bold icons to represent different game actions and elements.
- Design a layout with large, thumb-friendly buttons for easy interaction on mobile devices.
- Implement a timer animation that builds anticipation as the huddle breaks, such as a burning fuse or shrinking progress bar.
