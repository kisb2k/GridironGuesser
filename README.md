# Gridiron Guesser

The real-time sports prediction game for Football, Cricket, Baseball, Soccer, and Hockey.

## GitHub Versioning

To version this project on GitHub as a `master` branch, follow these steps in your terminal:

1. **Initialize Git**:
   ```bash
   git init
   ```

2. **Add all files**:
   ```bash
   git add .
   ```

3. **Commit the changes**:
   ```bash
   git commit -m "Initial commit: Master branch"
   ```

4. **Link to GitHub and Push**:
   Create a new repository on GitHub, then run:
   ```bash
   git remote add origin <your-repository-url>
   git branch -M master
   git push -u origin master
   ```

## Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Database/Auth**: Firebase Firestore & Auth
- **AI**: Genkit (Gemini 2.5 Flash)
- **Styling**: Tailwind CSS & ShadCN UI
